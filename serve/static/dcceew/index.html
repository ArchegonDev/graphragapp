Use case · Catalogue discovery

Find the datasets that actually answer the question.

A demonstration for the Department of Climate Change, Energy, the Environment and Water (DCCEEW). Someone asks for air-quality or emissions data in plain English. The graph links what they asked for to the datasets that hold it, and Jev decides whether to answer, ask for detail, refuse, or pass the request to a person.

Business question
Which official datasets answer this request?
What this proves
Catalogue discovery can be bounded: every request ends in one of five known outcomes.
Graph contribution
Links each pollutant to geography, time, breakdown, dataset and source, so coverage is checked rather than guessed.
Jev control
Answer, clarify, reject, review or no data. Nothing in between.

      How to read the result
      
        
      
          
      Answer
      The graph found datasets that hold the requested pollutants at the requested breakdown.
      
          
      Clarify
      The request is missing a detail Jev needs. It asks rather than guessing.
      
          
      Reject
      The catalogue cannot hold what was asked, so Jev stops before searching.
      
          
      Review
      A decision fell below the confidence threshold. A person should check it.
      
          
      No data
      The request was clear, but no combination of sources covers it.
      
        
      
        
      ScopeA demonstration catalogue of illustrative sources, decided by catalogue rules. No hosted model is called and request text is not logged.
